知乎采集器便携版

使用方法：
1. 将整个压缩包解压到一个有写入权限的目录。
2. 双击“知乎采集器.exe”。
3. 点击“登录知乎”，登录完成后再开始任务。
4. 采集结果保存在本文件夹下的 output 目录，文章在 output\...\markdown 中。

注意：
- 请不要只复制 exe，必须保留同目录下的 _internal 文件夹。
- 登录 Cookie 和浏览器配置保存在当前 Windows 用户的 %LOCALAPPDATA%\ZhihuCrawler，
  输出文件则保存在本便携版目录下。
- 若放在 C:\Program Files 等受保护目录，可能没有写入权限，请换到普通目录。
